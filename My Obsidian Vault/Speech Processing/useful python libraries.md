# Speech Processing
## Parselmouth
[Parselmouth website](https://parselmouth.readthedocs.io/en/stable/)
[Github](https://github.com/YannickJadoul/Parselmouth)

From the website:
> **Parselmouth** is a Python library for the [Praat](http://www.praat.org) software. 
> Though other attempts have been made at porting functionality from Praat to Python, Parselmouth is unique in its aim to provide a complete and Pythonic interface to the internal Praat code. While other projects either wrap Praat’s scripting language or reimplementing parts of Praat’s functionality in Python, Parselmouth directly accesses Praat’s C/C++ code (which means the algorithms and their output are exactly the same as in Praat) and provides efficient access to the program’s data, but _also_ provides an interface that looks no different from any other Python library.
>
> As a Python library, Parselmouth can be used in a **PsychoPy** experiment.
